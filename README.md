# 📊 CodeAlpha Data Science Internship Projects

This repository contains the projects completed during my **CodeAlpha Data Science Internship**. Each project demonstrates practical applications of data analysis and machine learning using Python and popular data science libraries.

# 🚀 Projects Included

## 📌 Task 1 – Iris Flower Classification

### Objective

Build a Machine Learning classification model to identify Iris flower species based on flower measurements.

### Highlights

* Data Exploration & Cleaning
* Logistic Regression
* K-Nearest Neighbors (KNN)
* Model Evaluation
* Confusion Matrix
* Classification Report
* Data Visualization

**Tools & Libraries**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 📌 Task 3 – Car Price Prediction using Machine Learning

### Objective

Develop a regression model to predict used car selling prices based on vehicle specifications.

### Highlights

* Data Preprocessing
* Feature Engineering
* One-Hot Encoding
* Linear Regression
* Model Evaluation
* Correlation Analysis
* Price Prediction
* Data Visualization

**Model Performance**

* **R² Score:** 0.85
* **MAE:** 1.22
* **RMSE:** 1.87

**Tools & Libraries**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
